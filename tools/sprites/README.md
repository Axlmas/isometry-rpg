# Рендер спрайтов из 3D-моделей

Инструмент превращает 3D-модели с анимациями в спрайт-листы для игры: каждый персонаж
рендерится в 8 направлениях, по несколько кадров на каждую анимацию. В сборку игры он не
входит и на сайт не попадает; в игре лежат только готовые листы в `public/sprites/`.

## Что нужно

- Node.js и браузер Chromium с Playwright (в среде разработки Claude уже есть).
- Модели. Их в репозитории нет. Скачайте оба набора в одну папку:

```bash
git clone --depth 1 https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
```

```bash
git clone --depth 1 https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0
```

## Как запустить

Один раз, в этой папке:

```bash
npm install
```

Отрендерить всех (аргумент — папка, в которую скачаны наборы):

```bash
node render.mjs /путь/к/папке/с/наборами
```

Только некоторых:

```bash
node render.mjs /путь/к/папке/с/наборами warrior mage
```

Результат — `public/sprites/<имя>.webp` и `<имя>.json`.

## Как устроено

- `characters.mjs` — список: какая модель, какие её части показывать (оружие, щит),
  какие анимации модели соответствуют анимациям игры (`idle`, `run`, `attack`, `hit`,
  `death`) и сколько кадров брать.
- `page.html` — сама отрисовка на three.js: камера под 30° к земле (так же, как видна
  земля в игре), свет, размер кадра, точка под ногами. Если меняете размер кадра
  (`FRAME`), поменяйте его и в `src/client/sheets.ts`.
- `render.mjs` — запускает браузер без окна, отдаёт ему модели и сохраняет листы.

Направления: 0 — вдоль оси x карты, дальше по кругу через ось y (1 — прямо на камеру).
Жители рендерятся только в направлении 1.

## Как добавить персонажа

1. Положить модель (`.glb` с анимациями) в папку с наборами.
2. Добавить запись в `characters.mjs`.
3. Запустить рендер для неё.
4. Подключить в `src/client/sheets.ts` (`HERO_SHEET`, `MONSTER_SHEET` или `NPC_SHEET`).
5. Записать источник и лицензию в `docs/ASSETS.md`.
