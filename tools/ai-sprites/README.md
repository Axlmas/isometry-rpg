# Спрайт-листы из сгенерированных картинок

`build.py` собирает спрайт-листы игры из картинок и анимаций, сгенерированных в SpriteCook
(см. `docs/ASSETS.md`). В сборку игры не входит; в игре лежат только готовые листы в
`public/sprites/`.

Нужны Python 3 и Pillow:

```bash
pip install pillow
```

Запуск (аргумент — папка со скачанными картинками, дальше имена персонажей; без имён
собирает всех, у кого есть `<имя>-front.png`):

```bash
python3 tools/ai-sprites/build.py /путь/к/картинкам wolf warrior-t0
```

Какие файлы ожидаются для персонажа `<имя>`:

- `<имя>-front.png`, `<имя>-back.png` — неподвижные картинки (вид спереди смотрит вниз-влево,
  вид сзади — вверх-вправо);
- `<имя>-run_front.png`, `<имя>-run_back.png`, `<имя>-attack_front.png`,
  `<имя>-attack_back.png`, `<имя>-death_front.png` — полосы квадратных кадров в один ряд.

Чего нет, то пропускается: жителю деревни достаточно одной `npc-…-front.png`.
