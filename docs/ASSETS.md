# Ассеты

Здесь записано всё, что в игре не нарисовано кодом: откуда взято, под какой лицензией
и как получено. Правило проекта: только свои ассеты или со свободной лицензией.

## 3D-модели (`public/models/*.glb`)

Сгенерированы нейросетью в сервисе **Tripo** (tripo3d.ai) через API на аккаунте
владельца проекта, по нашим текстовым описаниям. Это свои дизайны: в описаниях нет
названий чужих игр, персонажей или предметов. Права на результат — по условиям Tripo
для платного API-аккаунта владельца.

Удары, выстрелы и заклинания героя — не из файлов, а написаны в коде (`src/client/three/poses.ts`).

Как получены — `tools/tripo/README.md`. Каждый запрос (текст описания, параметры,
ID задачи) записан в `tools/tripo/tasks.jsonl`. Все концепты сделаны от одного
концепт-арта героя, поэтому модели в одном стиле. Исходники из Tripo в репозитории не
лежат; в игре — сжатые версии (`tools/models/optimize.mjs`).

| Файл | Что это в игре | Скелет и анимации |
|---|---|---|
| `hero-t0.glb` | герой без брони на теле (оборванец); алхимик | скелет Mixamo; покой, шаг, бег, урон, смерть |
| `hero-t1.glb` | герой в броне без грейда (кожа); кузнец, охотник, оружейник | то же |
| `hero.glb` (+ `hero-extra.glb`) | герой в броне с грейда D (латы); стражники, наставник | скелет Mixamo (65 костей); покой, шаг, бег, удар, урон, смерть, выстрел |
| `ghoul.glb` (+ `ghoul-extra.glb`) | шахтный упырь | скелет Mixamo; покой, шаг, бег, удар, урон, смерть |
| `wolf.glb` | волк, молодой волк (меньше), матёрый (крупнее) | скелет четвероногого; шаг. Галоп, хвост, голова, укус, отдача, падение — кодом |
| `boar.glb` | кабан, секач (крупнее) | то же, что у волка |
| `sword.glb`, `bow.glb`, `staff.glb` | оружие героя по классу | без скелета, в руке героя |
| `axe.glb` | топор кузнеца | без скелета |
| `oak.glb`, `fir.glb` | лиственный лес и ельник | без скелета; упрощены для тысяч копий |
| `boulder.glb`, `menhir.glb`, `ruin.glb` | валуны, стоячие камни, руины | без скелета |
| `house.glb` | дома деревни (растягивается под каждый квартал) | без скелета |

## Всё остальное

Земля, трава, кусты, частокол, вода, стены копей, свет, туман, эффекты, иконки предметов
и умений, интерфейс — код в `src/client/`, внешних ассетов нет.

Звуки синтезируются в браузере (`src/client/sound.ts`), аудиофайлов в игре нет.

Шрифты — системные, файлы шрифтов в игру не входят.
